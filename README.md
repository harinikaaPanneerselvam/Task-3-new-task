# SWYNEX Task 3 – Interactive Dashboard

## Project
Interactive Sentiment Dashboard built with Streamlit.

## Dataset
`analyzed_sentiment_data.csv` contains analyzed sentiment results aligned with the Task 2 sentiment-analysis project.

> Note: The included dataset is a small demonstration dataset prepared for the dashboard. If SWYNEX provided a specific analyzed dataset for Task 3, replace this CSV with that file while keeping the same column names or update the app accordingly.

## Features
- KPI cards
- Positive/Negative sentiment chart
- Confidence distribution chart
- Interactive sentiment filter
- Minimum-confidence filter
- Key findings section
- Filtered data table

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Technologies
Python, Streamlit, Pandas, Plotly
